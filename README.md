# 카드 가계부 (프로토타입)

카드 **문자** 또는 **이메일 영수증**을 붙여넣으면 금액·가맹점·날짜·카테고리를 **자동 인식**해 기록하는 웹 프로토타입입니다.

## 실행 방법
`index.html` 을 브라우저로 열면 바로 동작합니다. (설치·서버 불필요)

## 두 가지 자동 인식 모드
- **📱 카드 문자** — 안드로이드에서 수신 문자를 백그라운드로 읽어 자동 기록하는 방식의 데모. (iOS는 문자 접근 불가)
- **📧 이메일 영수증** — **아이폰 포함 모든 기기**에서 되는 방식. 실제 앱에서는 서버가 Gmail 등 메일함을 주기적으로 확인해 카드 영수증 메일을 같은 엔진으로 파싱해 자동 기록합니다.

두 모드 모두 동일한 파싱 엔진(`parseReceipt`)을 사용합니다.

## 아이폰에서 "자동 기록"이 되는 원리 (이메일 방식)
```
카드 결제 → 카드사가 이메일 영수증 발송 → (서버) 메일함 확인 →
영수증 파싱(금액/가맹점/날짜) → DB 저장 → 아이폰 앱이 조회해 표시
```
- 사용자는 아무것도 누르지 않아도 됨 = 진짜 자동
- iOS는 다른 앱 알림/문자를 읽을 수 없어, 이메일 파싱이 개인이 만들 수 있는 가장 자동에 가까운 방법
